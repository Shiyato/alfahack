# Инструменты

Вспомогательное, не входящее в горячий путь.

| Файл | Назначение |
|---|---|
| `export_codegraph.py` | выгрузка графа кода в `docs/codegraph.md` |

## Обновить граф кода

```bash
codegraph index                             # пересобрать индекс
uv run python tools/export_codegraph.py     # выгрузить в docs/
```

Индекс (`.codegraph/codegraph.db`) в репозиторий не кладётся: он
локален для машины, стареет при первой правке кода и конфликтует при
слиянии. В git живёт текстовая выгрузка, которая меняется вместе с кодом,
поэтому её расхождение с реальностью видно в ревью.

Зависимости строятся по связям `imports`, а не `calls`: вызовы в индексе
разрешаются по имени символа, и обычный `dict.get()` привязывается к
методу `get` любого класса проекта. Первая версия выгрузки из-за этого
показывала зависимость `admission → resilience`, которой в коде нет.

Слоистость дополнительно проверяется тестом `tests/test_layering.py` —
статически, по исходникам.
