Формат записи: **контекст → решение → последствия**. Смысл реестра —
заранее подготовить ответ на вопрос «а почему не X» и зафиксировать,
какое измерение стоит за решением.

Правило: если решение не опирается ни на измерение, ни на явно названный
компромисс — это не решение, а привычка, и его надо пересмотреть.
